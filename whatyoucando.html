What You can do with OMNEST™...

  • Design and Evaluate Networking Protocols


    • Build network models as virtual test beds for new and experimental protocols


    • Reuse your simulation code with no changes at all in your production systems. Complete transparency ensures nothing is hidden, so that you can safely rely on the simulation results.


    • With careful design, you can have common source for simulation and production code.



  • Use OMNEST™ as a Virtual Prototyping Environment for Various Networking Devices and Technologies


    • Alternative designs of switches, routers, network cards can be evaluated.


    • OMNEST™ can be used to serve as a testbed for optical and wireless solutions.


    • OMNEST™ can perform in "hardware in the loop" tests, where the virtual component modeled in the system is connected to a real network, with real traffic.



  • Evaluate Network Design Alternatives


    • Evaluate the performance of alternative networking solutions.


    • Perform cost calculations (if the cost of a component is available as a parameter, the total cost of a network can be calculated). This could be especially useful, when tendering to develop networks from standard components, to meet performance criteria.


    • Locate bottlenecks, demonstrate the effect of proposed changes, communicate benefits of your design.



  • Experiment With, and Perform Tests on Distributed Hardware Architectures


    • Interact with, model or test complex, distributed software systems involving web servers/web services, databases, file servers, legacy bank hosts, distributed component systems, and others.


    • Perform complex, non-linear experiments involving adaptive routing, fault tolerance, involving complex and heterogeneous networks (web applications/services/servers, file servers, legacy banking hosts, databases, distributed component systems, the list is endless.


    • Multiprocessor hardware architectures, adapter card hardware designs, other complex hardware architecture simulations and virtual prototyping.



  • Experiment with queueing networks


    • Classic example: bank tellers, fast-food restaurant throughput, etc. can be modeled and tested.


    • Call center simulation, design, and configuration.


    • Business process simulation and optimization.


    • Actually, any process, where some kind of sequence or queue is important can be effectively modeled and tested in OMNEST™. The uses are endless.
