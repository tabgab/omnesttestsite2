OMNEST™ 3.0 released

January 1st 2005

We at Omnest would like to take this opportunity to wish you a very happy New Year, and also present our season's greeting to you, start the New Year with a smile.

2004 has been a very successful year. Many prestigious companies have called on us to evaluate our simulation tools, and in an overwhelming number of cases, they never stopped using OMNEST™ since. This makes us very proud, but we also anticipate great things for 2005.

We have just managed to squeeze the release of OMNEST™ v.3.0 into 2004.

  • The simulation kernel has received an overhaul.

  • A new step-by-step tutorial, revised documentation and several new sample simulations have been included to shorten your learning curve.

  • Dynamic NED loading will cut model build time and simplify your work.

  • The NEDDoc tool will document your large simulation models, and help you quickly get into 3rd party models.

  • The new Random Number Architecture features a modern, very long cycle Random Number Generator for more realistic simulation results, and RNG mapping for more flexibility in simulation experiments.

  • Simulation models can now conveniently access XML configuration files for complex input.

  • Plove now features a powerful interactive charting component, and also an internal data-flow engine for processing output vectors before plotting.

  • The new Scalars tool complements Plove, and lets you analyze and plot scalar data produced by simulations.

  • Support for Parallel Distributed Simulation has been implemented.

  • Several Simulation GUI usability enhancements will save you time, and make your work more efficient.

  • New icons improve the overall look and feel of your models, while enhanced animation capabilities (icon coloring, queue length display, status text, transmission range, transient bubbles, etc.) give you more insight, and make the models instantly presentable.

  • For better visualization of model dynamics, OMNEST™ now supports animation of direct message sending and C++ method calls across modules.

  • The automatic network layouting algorithm will let you work with large networks in the GUI, without the need for individual positioning of nodes.

  • Ready to receive your extensions: plug-in interfaces for new random number generators, new configuration databases and simulation event schedulers complement existing plug-in interfaces for recording simulation data, and let you implement custom input/output, real-time simulation, hardware-in-the-loop simulation and more.

    • 2004 has seen the emergence of several open-source model frameworks based on OMNEST™/OMNeT++: IPv6Suite (for static and mobile IPv6 simulations), INET (for static TCP/IP networks), Mobility Framework (for wireless and ad-hoc networks)

    We hope you will give them a try in 2005.

    Have a Great New Year!
