What OMNEST™ Can Do for You

(Click on each title for details)

  • OMNEST™ Gives You Flexibility and Freedom In Building Your Models


    • Enjoy unlimited freedom in structuring your simulation. Build your models using an architecture you see fit: Each model is a set of active components that are connected via links and communicate by passing messages to each other. There are no predefined architectural constraints imposed upon you.

    • Use, share or build reusable components. Use ready-made components, or create your own. Defeat complexity using hierarchical design: combine existing components into larger, reusable components, or split a complex monolithic component into a combination of smaller ones.

    • Infinite Variety and Flexibility: Components may represent computers, servers, printers, switches, routers, mobile devices; protocol layers, applications, user behavior; shared communication channels like a cable or a wireless channel; networks, LANs, WANs; people; hardware elements such as CPUs, adapter cards, memory or disk; software components, processes, threads, queues, databases, web services; mobility behavior; virtual probes and measurement devices; "daemons" that watch and possibly control the simulation - just about anything is possible.

    • All components are reusable by nature; combine them freely as building blocks to produce new components or simulations of just about any kind.

    • The ultimate freedom any software package could offer: Tweak or extend or verify OMNEST™ to suit special needs. The source code is included; you can build a modified version* at any time.

      • * While you are free to use a modified version of OMNEST™ for your experiment, please refer to your license agreement for the details on the distribution of such code and binaries.


  • Consistent Separation of Model and Experiments


    • Separation of concerns: Write your model once, and then perform several experiments with it using different parameter settings, without having to change the model.

    • Random power for accurate results: Simulations with random conditions can also be explored. Parameters may take random values - no need to change the model if you want to use an exponentially distributed variate instead of normal distribution or a constant value.

    • Flexibility in parameters: Parameters can also change the topological aspects, such as the number of hosts on LAN, the number of ports in a switch, or the number of users on the system.

    • Versatile experiments: Using parameters, you can try different design alternatives without rewriting the model - you can also switch between several alternative implementations of the same component by setting a parameter value.


  • The Ability to Run Your Model in a Runtime Environment You Choose


    • OMNEST™ can be compiled to run on Windows, Linux, Unix, SUN Solaris and other systems too.


    • GUI or Command Line - take your pick: OMNEST™ does not want to argue the superiority of graphical, or command-line interfaces: it provides both and lets you choose the method that best suits your needs or working style.


    • No need to choose, you can use them both: Any simulation model may be run under a GUI or a command-line interface at any time - switching between the two is simple and fast.


    • Save time and effort by using a single code base: Use the GUI to develop, debug or demonstrate your simulation, and command-line to perform a series of experiments unattended.


    • Develop custom interfaces for custom uses: you can also create your own specialized GUIs (or non-GUI runtime environments) by customizing or replacing the GUI elements included in the package.



  • OMNEST's Powerful GUI Will Help You Reduce Time and Effort Expended in Developing, Debugging, and Demonstrating Simulations


    • Follow the simulation, exploring the model freely while the simulation is running. See the data flow right before your eyes.


    • Explore the simulation very deeply to trace events, or filter out possible bottlenecks in your architecture or logic.


    • Change parameters "on the fly" while the simulation is running, and discover the impact of the change.


    • Pause the simulation at any time, to see a snapshot of events, set the speed to slow, and follow what is happening, or concentrate on the results by setting lightning speed for maximum performance.


    • Extremely high-speed simulation yields superb performance. Setting the simulation speed to high will result in exactly that: Raw Power.


  • OMNEST™ Makes Building Models from Components Real Easy


    • High-level declarative language (NED) makes it possible to build simulations from ready-made, reusable components.


    • Automatic layout of complex topologies saves you time and effort.


    • NED lets you use hierarchical design to address complexity: combine existing components to form larger, reusable units.


    • NED allows for parametric topology creation.


    • YOU choose the tools for model building: you can write NED in your favorite text editor, or the graphical editor provided by OMNEST™. No need to commit yourself to one or the other - make one modification using emacs or vi, and the next one in the graphical editor.


    • The graphical editor allows for editing NED in text or graphic form: text and graphics will remain in-sync with each other at all times.


    • The NED compiler architecture is based on XML foundations. You can freely convert between NED and XML, and use XML/XSLT technologies to create NED files or extract information from existing NED files.

    • Advanced documentation facilities: OMNEST™ lets you generate hyperlinked model documentation from NED and C++ files, much like Javadoc or Doxygen.


  • OMNEST™ Lets You Build Components using a Powerful Simulation Library


    • Use industry standard C++ code to configure object logic and behavior.


    • Enjoy the benefits of round-trip engineering. Your test code, might as well be your final code, or become the basis of it.


    • Protocol headers, and other types of messages, which carry complex data structures can be represented very efficiently. OMNEST™ messages provide encapsulation support for arbitrarily complex data structures.


    • Accurate experiments may be carried out, thanks to random number generation uses modern, very long cycle generators such as Mersenne Twister and L'Ecuyer's object-oriented package.


    • Evaluation of results is supported by built in histogram classes, which may be set to automatically detect the range of observations and adapt to it. The library also contains implementation of the P2 algorithm which does on-line density approximation. One can also generate random numbers based on collected distributions. Modeling complex models and processes is boosted by built-in specialized classes to support queues and priority queues. Statistical classes compute mean, deviation, minimum/maximum value etc. Weighted statistics (e.g. for calculating time average) are also available.


    • OMNEST™ models are flexible and configurable, because they are parametric. Module parameter objects can hold string, double or integer variables, they can serve as a source of random variables and can also contain runtime-evaluated expressions of other parameters.


    • Collecting and evaluating data is supported by built-in result collection classes and methods, which arrange data collected during simulation to be recorded on disk or fed to a database for later evaluation.


    • Implementation of shortest path and routing algorithms is supported by powerful topology discovery support, allowing the extraction of model topology into a graph.



  • OMNEST™ Enhances Your Productivity


    • OMNEST™ is transparent.
      • The software itself is open source, you know exactly, what happens, what is running, and why.
      • The models can be explored even during runtime, with all parameters (and their changes) immediately visible. You can even make changes during run-time!
      • You can implement "hardware in the loop" simulations, where your virtual prototype can be examined as part of a real network, or system.
      • No secrets, no magic, everything happens right before your eyes, and there are no restrictions to what you can tweak in a simulation.

    • OMNEST™ is powerful, and flexible.
      • You can change the speed of a simulation at any time. Set it to "Warp" mode, and enjoy unequaled power, as your simulation is executed.
      • Uniquely, you can slow simulation time at any moment, to see how the project is doing, and examine the various messages, parameters, or states of your model. There is no need to stop the simulation for this, you might as well let it run, and see it in action!
      • You have really large models, or long simulations, OMNEST™ supports parallel simulation, so why not distribute extra long tasks among other hosts ?
      • With OMNEST™, you enjoy an unequaled combination of control and power.

    • OMNEST™ is accurate.
      • The system provides various Built-in Statistical distributions to explore deeply into your results: Continuous distributions: Gamma, Beta, Erlang, Chi 2, Student-t, Cauchy, Triangular, Lognormal, Weibull and Pareto.
      • Discrete distributions: Bernoulli, Binomial, Geometric, Negbinomial and Poisson.

  • OMNEST™ Provides Limitless Implementation Options Through its Open Architecture


    • The simulation kernel can be embedded into custom applications of your own (subject to license conditions). Integration is done on C++ level which gives you full control over details. You can simply use the simulation kernel via its C++ API, and link it into your application as a static or dynamic library.

    • Open, text-based output file formats allow easy integration with 3rd party tools such as MATLAB. You can also define alternative file formats or alternative means of output via plugin interfaces.

    • C++ plugin interfaces allow for customization and extension of the runtime environment.

    • Simulations are free to use or distribute as you please.

    • The strong academic user base of OMNEST™ ensures a broad supply of open-source simulation models of the latest networking technologies, as well as the availability of talented individuals who are already familiar with the OMNEST™ system.

  • OMNEST™ Scales Well, so You Can Run Very Large Models as Well


    • Supports multiple replications in parallel (MRIP) via the Akaroa 3rd party product.

    • Proven to run very large models.

    • Topology information for large networks may come from a variety of sources (including databases or XML files), and there are several ways to import it into OMNEST™ (including XML/XSLT and generating NED).

    • Parallel simulation capabilities let you take advantage of combined CPU power of multiprocessor systems, or allow for distributed execution of very large models that would not fit on a single computer.

    • No model modification or special instrumentation is necessary to use parallel simulation - any existing simulation can be run in parallel without modification. Partitioning is totally transparent for models (it is part of configuration), so you can easily try out alternatives for better load balancing.

    • Parallel simulation uses industry-standard MPI (Message Passing Interface) standard. MPI is not required on shared-memory architectures.
