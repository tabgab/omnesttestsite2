OMNEST™/OMNeT++ Features

  • Industry-standard C++ language, high performance simulation kernel:
    Simulation kernel provides high event/sec throughput, and presents a consistent object-oriented C++ API to the user
  • Wide range of applicability:
    Most contributed simulation models are about computer networks, but it has been successfully used for queuing networks, business processes and high-level hardware architectures as well
  • Hierarchical, component-based modelling:
    You build models from self-contained components, with arbitrary levels of nesting. Atomic components are programmed in C++, but no C++ is required to assemble them into larger components or simulation models.
  • Models are self-documenting:
    Documentation tool, comparable with Doxygen and providing integration with Doxygen, generates high-quality documentation with diagrams, tables and cross-references
  • Embeddable simulation kernel:
    Simulation kernel can be embedded into 3rd party products as a C++ class library
  • Parallel simulation:
    Parallel simulation on clusters or multiprocessors, using MPI and powerful conservative synchronization. Using named pipes or other communication means instead of MPI is also possible.
  • Source code available:
    Well-documented source code to increase your understanding, help debugging, and enable modifications
  • Standards support, open interfaces:
    Input and output files are plain text and/or XML, making it easy to process with 3rd party tools
  • GUI tools for building simulations and evaluating results:
    But you do not have to use the GUI -- everything is comfortably accessible using your text editor, command line and other tools as well.
  • Powerful GUI for tracing, debugging and animating your simulations:
    Not just animation playback! Much more powerful than that, you can peek into objects and variables in the C++ code, and even change them.
  • Extensibility:
    C++ plug-in interfaces made available to customize features of the simulation kernel. For example, it is easy to achieve that model configuration comes from a MySQL database, and results are written there as well -- without changing a line in the model itself.
  • Real-time, hardware-in-the-loop support:
    The simulation kernel supports real-time and hardware-in-the loop simulation via a plugin interface, and starting from a functioning and extensively commented source code example, you can quickly implement your own application-specific hardware-in-the-loop simulation.
  • Wide range of open-source simulation models:
    TCP/IP, IPv6, MPLS, wireless, mobile and ad-hoc simulations, TinyOS, port of the FreeBSD networking stack, queueing and several other open-source models are available from omnetpp.org and other websites.
  • Responsive and expert support:
    The developers answer, no need to get through dummy techsup personnel first.
